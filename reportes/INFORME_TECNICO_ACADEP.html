Arquitectura y saneamiento

V1 — Legacy (dada de baja)

WordPress + WooCommerce en mercagee_colonos (30.7 MB, 53 tablas), con backend de autenticación en Node.js sobre Google Cloud Run. Auditoría de wp_users: 8 de 9 cuentas administrativas con patrón de backdoor confirmado. Redirigida por completo a V2.0; no se reactivó ningún componente de esta arquitectura.

V2.0 — Arquitectura actual

Frontend Angular SPA (/administrator) + API REST bajo /api/v2. Base de datos consolidada desde mercagee_colonoscore (fuente real, 955 KB) hacia mercagee_v2_FidePaz_DB, con solo 6 tablas de negocio. Backend Go 1.26 + Gin compilado como binario único (arquitectura objetivo); backend PHP 8.2 nativo como fallback activo en producción mientras el hosting compartido no soporte procesos persistentes propios — mismo contrato de API, misma seguridad. Actualizado desde PHP 7.4 a 8.2 el 2026-08-05 (soporte de seguridad activo, versión con vida útil vigente).

Seguridad Zero Trust — controles activos

Autenticación

BCrypt (password_verify / bcrypt.CompareHashAndPassword) + JWT HS256 con expiración de 12h.

Acceso a datos

100% de las consultas SQL vía ? parametrizado (PDO / database/sql). Cero concatenación de strings en queries.

Superficie expuesta

8 endpoints explícitos bajo /api/v2, CORS por whitelist, rate limiting por IP en login y contacto.
